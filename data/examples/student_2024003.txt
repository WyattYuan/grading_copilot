[作答: q1]
列表和元组的区别：
- 列表可以改，元组不能改
- 列表用[]，元组用()
- 列表适合存储会变的数据，元组适合存储不变的数据

比如说，如果要存储班级里的学生名单，因为可能有转学的情况，所以用列表。如果要存储一个人的出生日期，就用元组，因为出生日期不会变。

[作答: q2]
```python
def sum_of_even_squares(nums):
    sum = 0
    for i in nums:
        if i % 2 == 0:
            sum = sum + i * i
    return sum
```

这个函数会遍历列表，找到偶数就平方然后加起来。

装饰器就是给函数添加功能的东西。它可以在不改变原来函数的情况下，给函数加上新的能力。

比如说，你有一个函数要计算很复杂的东西，你想知道它运行了多长时间，就可以写一个计时的装饰器，用@加在函数前面，这样每次运行函数都会自动显示运行时间。

装饰器的原理是：它接收一个函数，然后返回一个新函数，新函数里面会调用原来的函数，但是在调用前后可以做一些额外的事情。

[作答: q4]
```python
def fibonacci(n):
    if n == 0:
        return 0
    elif n == 1:
        return 1
    else:
        return fibonacci(n-1) + fibonacci(n-2)
```

用递归实现，如果n是0就返回0，如果是1就返回1，否则就是前两个数的和。
