```python
def sum_of_even_squares(nums):
    s = 0
    for n in nums:
        if n % 2 == 0:
            s = s + n**2
    return s
```

[作答: q4]
```python
def fibonacci(n):
    if n == 0 or n == 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)
```

斐波那契就是前两个数加起来，用递归写的话，0和1直接返回，其他的就递归调用。
