def fibonacci(n):
    if n <= 1:
        return n
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b

依赖注入(DI)是指不在类内部创建依赖对象,而是通过构造函数、属性或方法参数从外部传入。
优点:
1. 降低模块间的耦合
2. 方便进行单元测试(可以注入mock对象)
3. 提高代码的灵活性和可扩展性
