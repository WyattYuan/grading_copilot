列表和元组的区别：

1. 列表是可变的，可以修改、添加、删除元素；元组是不可变的，创建后不能改变。

2. 列表用方括号[]，元组用圆括号()。

3. 使用场景：列表用在需要改变数据的时候，比如存储学生成绩，可以随时更新。元组用在数据固定的场景，比如存储日期(年,月,日)，因为日期一旦确定就不应该改了。元组还可以作为字典的key，列表不行。

def sum_of_even_squares(nums):
    result = 0
    for num in nums:
        if num % 2 == 0:  # 判断是否为偶数
            result += num ** 2  # 累加平方
    return result

# 测试一下

装饰器是用来修改函数功能的工具。它的原理是接收一个函数，然后返回一个新的函数，新函数会在原函数的基础上添加一些额外的功能。

装饰器使用@符号来应用，比如：
```python
@decorator_name
def my_function():
    pass
```

实际应用例子：比如在web开发中，可以用@login_required装饰器来检查用户是否登录，如果没登录就跳转到登录页面。还有@cache装饰器可以缓存函数的结果，避免重复计算。

```python
def fibonacci(n):
    if n == 0:
        return 0
    if n == 1:
        return 1
    return fibonacci(n-1) + fibonacci(n-2)
```

这个函数通过递归实现，F(0)=0，F(1)=1，其他情况就是前两项之和。
