### 题目详情

#### Q1: 列表和元组的区别 (10分) - 理论题
**题目描述：**
请简述Python中列表(list)和元组(tuple)的区别，并说明各自的使用场景。

**评分标准：**
- 3分：正确说明列表是可变的，元组是不可变的
- 3分：说明定义方式的区别（方括号vs圆括号）
- 4分：给出合理的使用场景，并解释为什么

**考查要点：**
- 数据结构的可变性理解
- 实际应用场景的思考
- 表达能力

---

#### Q2: 偶数平方和函数 (15分) - 编程题
**题目描述：**
编写一个Python函数，接收一个整数列表作为参数，返回列表中所有偶数的平方和。
例如：输入[1,2,3,4,5,6]，返回2²+4²+6²=56

**评分标准：**
- 5分：函数定义正确，参数和返回值符合要求
- 5分：正确判断偶数（使用模运算或其他有效方法）
- 3分：正确计算平方
- 2分：代码简洁优雅（加分项）

**考查要点：**
- 函数定义能力
- 循环和条件判断
- 数学运算
- 代码质量

---

#### Q3: 装饰器原理 (12分) - 理论题
**题目描述：**
什么是Python装饰器(decorator)？请解释其基本原理并举一个实际应用的例子。

**评分标准：**
- 4分：正确说明装饰器是高阶函数，接收函数返回函数
- 4分：解释基本原理（闭包、不修改原函数等）
- 4分：给出实际应用例子并说明用途

**考查要点：**
- 高级特性理解
- 设计模式认知
- 实际应用能力

---

#### Q4: 斐波那契递归 (13分) - 编程题
**题目描述：**
使用递归实现斐波那契数列的计算。编写函数fibonacci(n)，返回第n个斐波那契数。
（斐波那契数列：0,1,1,2,3,5,8,13...，其中F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)）

**评分标准：**
- 5分：正确实现递归基础条件（n=0返回0，n=1返回1）
- 6分：正确实现递归调用（F(n)=F(n-1)+F(n-2)）
- 2分：考虑边界情况处理（如n<0的情况）

**考查要点：**
- 递归思维
- 边界条件处理
- 算法实现能力

## 🚀 使用方法

### 1. 生成测试用例
```bash
uv run python create_test_case.py
```

### 2. 在UI中测试
1. 启动后端服务：
   ```bash
   uv run python run_api.py
   ```

2. 启动前端界面：
   ```bash
   uv run python run_ui.py
   ```

3. 在"新建评分任务"页面：
   - 上传 `test_exam_config.json`
   - 上传 `test_student_answers.zip`
   - 点击"开始评分"

4. 在"任务状态"页面监控进度

5. 在"评分结果"页面查看：
   - 总体统计
   - 分数分布图
   - 各学生详细报告

6. 在"人工微调"页面可以调整AI评分
