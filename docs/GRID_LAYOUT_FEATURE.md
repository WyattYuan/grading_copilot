# 📊 田字格布局功能说明

## 🎯 功能概述

在**评分结果**和**人工微调**界面中，每道题目的详情现在采用**田字格布局**，将信息分为四个区域，便于对比和审查。

## 📐 布局设计

```
┌─────────────────────────┬─────────────────────────┐
│   ✍️ 学生答案          │   📊 评分标准          │
│                         │                         │
│   (左上)                │   (右上)                │
│                         │                         │
├─────────────────────────┼─────────────────────────┤
│   📖 参考答案          │   🤖 AI评分依据        │
│                         │                         │
│   (左下)                │   (右下)                │
│                         │                         │
└─────────────────────────┴─────────────────────────┘
```

### 区域说明

| 位置     | 内容       | 说明                           |
| -------- | ---------- | ------------------------------ |
| **左上** | 学生答案   | 学生实际提交的答案内容         |
| **左下** | 参考答案   | 标准答案或参考答案             |
| **右上** | 评分标准   | 详细的评分标准，包含各项得分点 |
| **右下** | AI评分依据 | AI给出的评分理由和扣分说明     |

---

## 🎨 界面特点

### 1. 对比方便
- **左列**：学生作答 vs 参考答案，便于对比正确性
- **右列**：评分标准 vs AI评分依据，便于检查评分合理性

### 2. 固定高度
- 每个区域高度固定为 250px
- 内容过长时自动滚动
- 保持四个区域对齐，视觉整齐

### 3. 清晰标识
- 每个区域都有图标和标题
- 使用边框容器（`border=True`）增强视觉分隔
- 空内容显示友好提示

## 📋 应用场景

### 评分结果页面（📈 评分结果）

**用途：** 查看AI评分结果

**特点：**
- 只读展示，不可编辑
- 快速浏览所有题目的评分情况
- 对比学生答案和参考答案
- 查看AI的评分依据

**操作流程：**
1. 选择任务和学生
2. 展开题目详情
3. 查看田字格布局的完整信息
4. 如需调整，切换到"人工微调"页面

### 人工微调页面（✏️ 人工微调）

**用途：** 审查和调整AI评分

**特点：**
- 同样的田字格布局

## 🔍 数据来源

### QuestionSnapshot 模型

```python
class QuestionSnapshot(BaseModel):
    """题目快照(用于报告)"""
    
    description: str              # 题目描述
    max_score: float              # 满分
    reference_answer: str         # 参考答案
    scoring_criteria: Optional[str]  # 评分标准（新增）
```

### 评分标准格式

评分标准从 `Question.scoring_criteria` 自动格式化：

**输入：**
```json
"scoring_criteria": [
    {"points": 3, "criterion": "正确说明列表是可变的，元组是不可变的"},
    {"points": 3, "criterion": "说明定义方式的区别（方括号vs圆括号）"},
    {"points": 4, "criterion": "给出合理的使用场景，并解释为什么"}
]
```

**输出：**
```
1. (3分) 正确说明列表是可变的，元组是不可变的
2. (3分) 说明定义方式的区别（方括号vs圆括号）
3. (4分) 给出合理的使用场景，并解释为什么
```

## 💻 技术实现

### Streamlit 布局代码

```python
# 田字格布局：左列 | 右列
left_col, right_col = st.columns(2)

with left_col:
    # 左上：学生答案
    st.markdown("**✍️ 学生答案**")
    with st.container(border=True, height=250):
        st.write(q["student_answer"])
    
    # 左下：参考答案
    st.markdown("**📖 参考答案**")
    with st.container(border=True, height=250):
        st.write(q.get("reference_answer", "暂无"))

with right_col:
    # 右上：评分标准
    st.markdown("**📊 评分标准**")
    with st.container(border=True, height=250):
        st.write(q.get("scoring_criteria", "暂无"))
    
    # 右下：AI评分依据
    st.markdown("**🤖 AI评分依据**")
    with st.container(border=True, height=250):
        st.write(q["ai_rationale"])
```

### 关键特性

1. **st.columns(2)** - 创建两列布局
2. **st.container(border=True, height=250)** - 固定高度的边框容器
3. **height参数** - 确保四个区域对齐
4. **border=True** - 添加边框增强视觉效果

## 📊 优势对比

### 之前的布局（纵向排列）

```
题目描述
─────────
学生答案
─────────
AI评分依据
─────────
（需要上下滚动查看）
```

**缺点：**
- ❌ 无法同时看到学生答案和参考答案
- ❌ 评分标准和AI依据不在一起
- ❌ 需要频繁滚动
- ❌ 对比不方便

### 现在的布局（田字格）

```
┌──学生答案──┬──评分标准──┐
├──参考答案──┼──AI依据───┤
```

**优点：**
- ✅ 左列对比：学生答案 vs 参考答案
- ✅ 右列对比：评分标准 vs AI评分依据
- ✅ 四个区域同时可见
- ✅ 逻辑清晰，审查效率高

## 🎯 使用建议

### 1. 审查流程

1. **先看左列**
   - 对比学生答案和参考答案
   - 判断答案的正确性和完整性

2. **再看右列**
   - 查看评分标准的要求
   - 检查AI评分依据是否合理

3. **综合判断**
   - 是否按评分标准给分
   - AI扣分理由是否充分
   - 是否需要人工调整

### 2. 快速定位

- **🟢 绿色** - 得分率 ≥ 80%，通常无需调整
- **🟡 黄色** - 得分率 60-80%，建议重点审查
- **🔴 红色** - 得分率 < 60%，需要仔细检查

### 3. 人工微调原则

- 对照评分标准逐项检查
- AI遗漏的得分点可以补充
- AI过度扣分的可以调整
- 调整理由要具体说明原因
