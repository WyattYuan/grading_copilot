# 📋 任务名称格式 - 快速参考

## 🎯 新格式

```
考试名称 (YYYY-MM-DD HH:MM:SS) [N人]
```

## 📝 示例

### 完整格式
```
Python程序设计期中考试 (2025-11-01 14:30:25) [5人]
├─ Python程序设计期中考试 ← 考试名称
├─ (2025-11-01 14:30:25) ← 创建时间（精确到秒）
└─ [5人] ← 学生数量
```

### 同一天的不同任务
```
Python程序设计期中考试 (2025-11-01 14:30:25) [5人]  ← 第1次运行
Python程序设计期中考试 (2025-11-01 15:45:30) [5人]  ← 第2次运行
Python程序设计期中考试 (2025-11-01 16:20:15) [3人]  ← 第3次运行（学生数不同）
```

✅ **现在可以轻松区分了！**

## 🔍 不同场景的显示

| 场景     | 显示格式                  | 示例                                     |
| -------- | ------------------------- | ---------------------------------------- |
| 完整信息 | `考试名 (时间) [N人]`     | `期中考试 (2025-11-01 14:30:25) [5人]`   |
| 无学生数 | `考试名 (时间)`           | `期中考试 (2025-11-01 14:30:25)`         |
| 无时间戳 | `考试名 [N人]`            | `期中考试 [5人]`                         |
| 无考试名 | `未命名考试 (时间) [N人]` | `未命名考试 (2025-11-01 14:30:25) [5人]` |
| 仅考试名 | `考试名`                  | `期中考试`                               |

## ✨ 优点

- ✅ **唯一性**：时间精确到秒，几乎不会重复
- ✅ **信息丰富**：一眼看到考试、时间、人数
- ✅ **易识别**：快速定位想要的任务
- ✅ **自动排序**：按时间顺序自然排列

## 📊 在UI中的使用

任务名称会在以下位置显示：

1. **📊 任务状态** - 选择要查看的任务
2. **📈 评分结果** - 选择要查看的评分报告
3. **✏️ 人工微调** - 选择要微调的任务

所有地方都使用统一的友好格式！

## 🎓 使用提示

### 💡 提示1：设置有意义的考试名称
在考试配置JSON中：
```json
{
  "exam_title": "Python程序设计期中考试",  // ← 这里设置
  "questions": [...]
}
```

### 💡 提示2：系统自动记录
- ⏰ **时间戳**：任务创建时自动记录
- 👥 **学生数**：上传答案后自动统计

无需手动设置！

### 💡 提示3：避免重复测试时的混淆
如果在短时间内多次测试，建议：
- 修改考试名称（如添加"测试1"、"测试2"）
- 或者查看完整的时间戳来区分
