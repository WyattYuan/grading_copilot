# 🎉 UI 优化功能使用指南

## 快速开始

### 1. 安装依赖
确保已安装最新依赖（包含 plotly）：
```bash
uv sync
```

### 2. 启动服务
```bash
# 终端1：启动后端 API
uv run python run_api.py

# 终端2：启动 UI 界面
uv run python run_ui.py
```

## 🆕 新功能一览

### 1. 启动时自动检测后端服务

**功能描述：**
- 启动 UI 时自动检测后端 API 是否可用
- 如果后端未启动，会显示友好提示

**效果截图位置：**
页面顶部会显示：
```
❌ 无法连接到后端服务 (127.0.0.1:8000)，请先启动 API 服务
💡 请先运行后端API服务：uv run python run_api.py
```

**使用建议：**
确保按照正确顺序启动服务（先 API 后 UI）

### 2. 系统状态面板

**功能位置：** 页面顶部可展开区域

**包含信息：**
- 后端服务状态（运行中 ✅）

- 刷新状态按钮

**如何使用：**

### 3. 搜索任务功能

**功能位置：** 左侧边栏

**如何使用：**
1. 在左侧边栏找到 "🔍 搜索任务" 输入框

### 7. 数据可视化分析 ⭐⭐⭐

**功能位置：** "📋 评分结果" 标签页

**三个可视化子标签：**

#### 📈 总体统计
**包含 8 个统计指标：**
- 学生总数
- 平均分
- 最高分
- 最低分
- 中位数
- 标准差
- 及格率（≥60分）
- 优秀率（≥85分）

#### 📊 分数分布
**包含 3 种图表：**

1. **分数分布直方图**
   - 20个分数段
   - 清晰显示分数集中区域

2. **箱线图**
   - 显示数据分布范围
   - 识别异常值

3. **分数段饼图**
   - 不及格(<60)
   - 及格(60-70)
   - 中等(70-80)
   - 良好(80-90)
   - 优秀(90-100)

#### 🎯 题目分析
**功能：**
- 各题平均分对比柱状图
- 帮助识别难题和易题
- 数据表格详细展示

**如何使用：**
1. 选择一个已完成的任务
2. 点击 "📈 总体统计" / "📊 分数分布" / "🎯 题目分析" 标签
3. 查看不同维度的数据分析
4. 所有图表支持交互（悬停查看详情、缩放等）

### 8. 排序和排名功能

**功能位置：** "📋 评分结果" 标签页的总分表上方

**可用选项：**
- **排序方式：** 总分 / 学号
- **排序顺序：** 升序 / 降序（默认降序）
- **自动添加排名列**

**如何使用：**
1. 在下拉框选择排序方式
2. 勾选/取消"升序"复选框
3. 表格自动更新，显示排名

**示例：**
- 按总分降序 → 显示成绩从高到低排名
- 按学号升序 → 按学号顺序查看成绩

## ⚠️ 常见问题

### Q1: 启动后显示"无法连接到后端服务"
**A:** 请先启动后端 API 服务
```bash
uv run python run_api.py
```

### Q2: 任务列表显示的数据不是最新的
**A:** 
1. 点击侧边栏的 "🔄 刷新列表" 按钮
2. 或点击系统状态面板的 "🔄 刷新状态"

### Q3: 图表显示不出来
**A:** 确保已安装 plotly 依赖
```bash
uv add plotly
```

### Q4: 搜索功能找不到任务
**A:** 
- 检查搜索关键词是否正确
- 搜索是模糊匹配，尝试使用部分关键词
- 清空搜索框查看所有任务

### Q5: 自动刷新功能不工作
**A:** 
- 确保勾选了 "自动刷新" 复选框
- 只有 pending 和 running 状态的任务会自动刷新
- 已完成或失败的任务不需要自动刷新
